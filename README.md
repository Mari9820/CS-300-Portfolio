# CS-300-Portfolio
Portfolio for CS 300: Data Structures and Algorithms
CS-300 Portfolio Reflection

Throughout this course, I worked on projects that focused on organizing, storing, and retrieving course information using different data structures. The main goal was to create a program that could load course information, display courses in alphanumeric order, and show prerequisites for a selected course. These projects helped me understand how important it is to choose the right data structure when developing a program.

My approach was to break the projects down into smaller steps and understand how each data structure worked before putting everything together. I learned that vectors, hash tables, and binary search trees each have their own advantages depending on what the program needs to accomplish. I also ran into challenges with my code, especially when dealing with compilation errors and getting everything to run correctly. I worked through these issues by reviewing my code, making corrections, and testing it again until I got the expected results.

These projects helped me become more comfortable with designing software and thinking about how a program should function before writing the code. I also learned the importance of keeping code organized, readable, and easy to update. Using functions, clear naming, and a structured approach makes it easier to identify problems and make changes without affecting the entire program. Overall, this course has helped me improve my problem-solving skills and become more confident in working with data structures and algorithms.
